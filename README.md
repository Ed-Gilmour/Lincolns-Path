# Lincoln's Path

## About
Step into Lincoln’s shoes in this free decision-making web game. Lincoln's Path is great for people who are looking to learn about Lincoln's presidency and the Civil War. Experience the challenges of his presidency and see if you can make it to the end.

## Features
* Over 50 events
* Strategic gameplay that involves balancing decisions
* A timeline to see how you acted compared to Lincoln
* Events that occur dependent on previous decisions
* An easter egg and a secret ending

## How to Play
Lincoln's path is available on the web to play: [Play Game](https://ed-gilmour.github.io/Lincolns-Path/)

## Tools Used
Lincoln's path was built in Unity with C# and WebGL.
